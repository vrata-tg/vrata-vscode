# Инструкции проекта

Прочитай и соблюдай `AGENTS.md` в корне этого репозитория.

Всегда завершай задачи с изменениями кода или конфигурации коммитом,
пушем отдельной рабочей ветки и открытием pull request в `main`.
Если PR этой ветки уже открыт, обновляй его. Дополнительное подтверждение
на пуш ветки и открытие PR не требуется. В итоговом ответе указывай ссылку
на PR и результаты проверок. Не мержи PR без явного указания пользователя.
