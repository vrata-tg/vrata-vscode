# Подключение Врат AI

Вставьте ваш API-ключ из бота Врата AI.

Управление расширением доступно через **Chat → Manage Models → Врата AI**, команду **Врата AI: Управление подключением** и индикатор Врата AI в строке состояния справа внизу.

После подключения нажмите **Выбрать модель** в уведомлении или панели. В штатном picker-е VS Code откройте **Other Models** и выберите провайдера **Врата AI**. VS Code запомнит выбор для следующих чатов. Если доступные модели изменились, выполните команду **Врата AI: Обновить список моделей**.
