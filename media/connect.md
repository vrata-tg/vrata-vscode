# Один ключ для Врата AI

Вставьте существующий API-ключ из бота. Поле скрывает ввод; старый ключ сохраняется, пока новый не пройдёт проверку.

Управление доступно через **Chat → Manage Models → Врата AI**, команду **Врата AI: Управление подключением** и индикатор Врата AI в строке состояния.

**Каталог и баланс пока не подключены.** Этот выпуск сохраняет и проверяет ключ; выбор моделей появится в следующем этапе MVP.

Удаление ключа отключает только этот профиль VS Code. Ключ в боте и других инструментах продолжит работать.
