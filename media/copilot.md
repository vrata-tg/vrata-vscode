# Copilot Chat — необязательный альтернативный интерфейс

GitHub Copilot Chat, если он установлен, тоже видит модели Врат AI после
подключения ключа: выберите провайдера **Врата AI** в меню моделей чата.

Copilot **не требуется** для работы расширения: собственный агент `@vrata`
во встроенном чате работает всегда (см. шаг «Откройте агента Врата»).

Панель **Врата AI** в Activity Bar управляет подключением: ключ, баланс,
квота, модель и reasoning level.

Copilot не установлен? Нажмите кнопку выше — расширение предложит страницу
в Marketplace для установки. Работа без Copilot подтверждена: агент Врата
использует только документированные API редактора.
