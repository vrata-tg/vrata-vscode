# Copilot Chat — стартовый агент

GitHub Copilot Chat уже видит модели Врат AI после подключения ключа:
выберите провайдера **Врата AI** в меню моделей чата и работайте готовым
агентом — с инструментами, файлами и терминалом.

Панель **Врата AI** в Activity Bar управляет подключением: ключ, баланс,
квота, предпочитаемая модель и reasoning level.

Copilot не установлен? Нажмите кнопку выше — расширение предложит страницу
в Marketplace для установки.
