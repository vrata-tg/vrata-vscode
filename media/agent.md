# Агент Врата — встроенный чат без Copilot

У расширения есть собственный агент `@vrata` во встроенном чате VS Code.
Он не зависит от GitHub Copilot: работает на моделях Врат AI через
Language Model Provider API самого редактора.

## Что умеет агент

- Инструментальный цикл: читает файлы, правит код, запускает терминал —
  через штатные инструменты редактора (`vscode.lm.invokeTool`).
- Берёт модель из панели «Врата AI» (или модель, выбранную в чате).
- Передаёт ваш reasoning level из панели в каждый запрос.

## Как начать

1. Нажмите кнопку **Открыть агента Врата** в шаге выше (или в панели
   «Врата AI» — пункт «Открыть агента Врата в чате»).
2. В поле чата напишите задачу: `@vrata исправь тесты в этом проекте`.
3. Следите за шагами агента прямо в чате.

Если встроенный чат недоступен в вашей сборке редактора, команда сообщит
об этом — обновите VS Code до 1.104+.
