# Для чего нужна служебная модель

VS Code иногда отправляет фоновые запросы — например, чтобы автоматически
придумать название чата или выполнить другое вспомогательное действие. Это не
сообщение пользователя в чате, но такой запрос всё равно использует модель и
может расходовать баланс Врат AI.

Нажмите **Настроить служебную модель** и выберите **Main Agent Model**. Простыми
словами: для таких фоновых запросов VS Code будет использовать выбранную вами
модель основного агента Врата AI. Это не отдельный чат и не новый API-ключ.

Если настройка недоступна, используйте более новую версию VS Code — расширение
сообщит об этом после нажатия кнопки.
