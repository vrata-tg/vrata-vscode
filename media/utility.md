# Контролируйте расходы

Редактор может отправлять дополнительные запросы, например для заголовков чатов. Они также оплачиваются по тарифам Врата AI.

Если ваша версия VS Code поддерживает настройку служебной модели, выберите **mainAgent** на вкладке **User**. В старых версиях настройка может отсутствовать: кнопка сообщит об этом. Расширение не меняет ваши настройки автоматически.

Используйте встроенный **local Agent**. Разрешения на чтение файлов, запуск команд и доверие к рабочей папке контролирует VS Code.
