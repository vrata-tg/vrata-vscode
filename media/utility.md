# Настройка служебной модели

Редактор может отправлять дополнительные запросы, например для заголовков чатов. Они также оплачиваются по тарифам Врата AI.

Чтобы настроить служебную модель, нажмите слева кнопку "Настроить служебную модель" и выберите вариант "Main Agent Model". В старых версиях Visual Studio Code настройка может отсутствовать: кнопка сообщит об этом.
