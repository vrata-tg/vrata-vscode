# Служебная модель

VS Code отправляет фоновые запросы, например для названия чата.
Они тоже могут расходовать баланс.

Нажмите **Настроить служебную модель** и выберите **Main Agent Model**,
чтобы фоновые запросы использовали модель основного агента.
Если настройка недоступна, расширение предложит обновить VS Code.
