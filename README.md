# Врата AI для VS Code

Подключите модели Врата AI к чату VS Code и работайте с кодом в привычном
интерфейсе Copilot Chat. Для подключения нужен API-ключ из
[бота Врата AI](https://vrata.tg/bot).

Расширение позволяет:

- выбирать модели Врата AI прямо в чате;
- видеть баланс аккаунта и имя подключённого ключа в боковой панели;
- настраивать уровень рассуждений для поддерживаемых моделей;
- менять API-ключ без редактирования файлов настроек.

## Быстрый старт

Нужен **VS Code 1.104.0 или новее** с установленным и включённым
[GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat).
В новых версиях VS Code он встроен. Старое расширение **GitHub Copilot** устарело.
Рабочая папка должна быть доверенной.

1. Откройте [бота Врата AI](https://vrata.tg/bot) и создайте или скопируйте
   ключ в разделе **API-ключи**.
2. Нажмите значок **Врата AI** на боковой панели VS Code.
3. Выберите **Подключить / заменить ключ** и вставьте API-ключ.
4. Нажмите **Выбрать модель в чате**, выберите модель Врата AI
   и отправьте сообщение.

В новом меню выбора моделей откройте вкладку **Врата AI**. В старом меню
откройте шестерёнку в **Other Models**, найдите провайдера **Врата AI**
и закрепите нужные модели, затем выберите одну из них в чате.

Пошаговую инструкцию можно открыть в любой момент: вызовите палитру команд
(`Ctrl+Shift+P`, на macOS — `Cmd+Shift+P`) и выберите
**Врата AI: Как начать работу**.

## Баланс и API-ключ

Запросы к моделям расходуют баланс Врата AI. Посмотреть баланс можно в панели
расширения, а пополнить — в [боте](https://vrata.tg/bot).

API-ключ хранится в защищённом хранилище VS Code. Чтобы заменить его,
нажмите строку с именем ключа в панели. Если новый ключ не пройдёт проверку,
прежнее подключение сохранится.

## Уровень рассуждений

Нажмите **Уровень размышлений** в строке состояния или выполните команду
**Врата AI: Выбрать reasoning level**. Выбор сохраняется для профиля VS Code.
Вариант **По умолчанию** оставляет выбор уровня серверу.

Для отдельной модели можно задать свой уровень в `settings.json`:

```json
{
  "vrata.reasoningEffortByModel": {
    "gpt-6-astra": "high"
  }
}
```

Настройка модели имеет приоритет над общим уровнем. Поддержка этой настройки
и доступные уровни зависят от выбранной модели.

## Служебные запросы

VS Code использует отдельную служебную модель, например для названий чатов.
Такие запросы тоже могут расходовать баланс.

В инструкции **Врата AI: Как начать работу** нажмите
**Настроить служебную модель** и выберите **Main Agent Model**, если хотите
использовать для них модель основного агента. Эта настройка доступна
в новых версиях VS Code.

## Если что-то не работает

- **Чат просит настроить Copilot, запрос не появляется в логах Врата.**
  Проверьте **GitHub Copilot Chat**: откройте расширения и найдите
  `@id:GitHub.copilot-chat`. Если он отключён, включите его. В VS Code 1.143.1
  отдельная кнопка включения встроенного Chat может быть недоступна. В таком
  случае через палитру команд выполните **Extensions: Enable All Extensions**,
  затем **Developer: Reload Window** и откройте новый локальный чат.
  **Enable All Extensions включает все отключённые расширения**, включая те,
  которые вы могли отключить намеренно.
- **Нет моделей или не обновляется баланс.** Выполните команду
  **Врата AI: Управление подключением** → **Обновить каталог и аккаунт вручную**.
- **Запрос завершился ошибкой.** Нажмите **Открыть журнал** в уведомлении.
  Журнал также доступен через **Врата AI: Управление подключением** →
  **Отладочные логи**.
- **Нужна помощь.** Создайте [issue в репозитории](https://github.com/vrata-tg/vrata-vscode/issues).
  Укажите версию VS Code, модель и текст ошибки. Если в уведомлении есть
  **Скопировать диагностику**, приложите её содержимое. API-ключ публиковать не нужно.
