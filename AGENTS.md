# Инструкции для агентов

## Завершение задач

- Выполняй изменения в отдельной рабочей ветке. Не коммить и не пушь напрямую в `main`.
- После реализации и успешных проверок всегда создай коммит, запушь рабочую ветку в `origin` и открой pull request в `main`.
- Если для этой ветки уже открыт pull request, отправь изменения в ту же ветку и используй существующий PR.
- Не останавливайся на локальных изменениях. Пуш ветки и открытие PR входят в задачу и не требуют дополнительного подтверждения пользователя.
- В итоговом ответе дай ссылку на PR и кратко укажи результаты проверок. Если публикация заблокирована, сообщи конкретную причину.
- Не мержи PR без явного указания пользователя.

## Проверки

- Установи зависимости командой `npm ci` и запусти `npm test`.
- При изменениях сборки или релиза проверь `npm run package`.

## Заметки

Заметки, отчёты и полезные находки по Vrata сохраняй в
https://github.com/v-lebedev/vrata-docs, следуя `AGENTS.md` того репозитория.
